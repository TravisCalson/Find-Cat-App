# 找猫猫 - 安卓 APP

n×n 网格中隐藏 n 只猫猫，每行、每列、每个颜色区域各一只，且任意两只猫猫不相邻。

## 构建

```bash
export JAVA_HOME="/c/Program Files/Microsoft/jdk-21.0.12.101-hotspot"
export ANDROID_HOME="/c/Users/Mi/AppData/Local/Android/Sdk"
cp "E:\ddr-price-tracker-backup\find-cats.html" www/index.html
npx cap sync android
cd android && ./gradlew assembleDebug
cp android/app/build/outputs/apk/debug/app-debug.apk 找猫猫.apk
```

### v1.3.2 (2026-09-30 20:15)

**关卡生成算法重写——解决无法生成关卡问题**
- 弃用旧的 `placeCats`（内嵌求解+再生成循环），改为「随机BFS区域 + 唯一解检测重试」
- 新增 `countSolutions` 求解器：MRV + 前向检验，统计解数（上限2），恰好1解才接受
- 生成流程：循环生成随机BFS区域 → 求解验证唯一性 → 不唯一则重新生成，8秒内必定找到
- 移除网格递减逻辑（n=10不再降级），保持5~10全尺寸支持
- 经测试：n=5~10 全部 20/20 成功生成唯一解关卡（n=10 平均1.4秒）

### v1.3.1 (2026-09-30 19:30)

**关卡生成修复**
- 移除有缺陷的 `isUniqueSolution` 二次验证（只查单猫同行移动，永远检测不到替代解）
- 改用 `searchComplete` 标志：搜索超时则不接受解，搜索完成且恰好 1 解才确认唯一
- `placeCats` 算法重写：前向检验 + MRV（最少剩余值）启发式，搜索速度大幅提升
- 网格 5~10 全部支持，共享 8s 生成上限（不再逐级递减卡死）
- 移除生成前重置 `cats`，防止旧关卡残留数据被误用
- 兜底排列改为先奇数列后偶数列（任意 n≥5 保证不相邻），修复偶数 n 时列重复

- localStorage 不可用时初始化崩溃（全部调用加 try/catch）
- 退出对话框按返回键可绕过（重新 pushState 拦截）
- 自定义对话框后又弹原生确认框（`exiting` 标志抑制 `beforeunload`）
- "不保存"退出后游戏卡住且永远无法存档（改用 `App.exitApp()`）
- 重玩旧关卡颜色错误或相邻同色（`regionColors` 存入 `levelHistory`）
- 谜题生成失败后 `cats` 未初始化崩溃（兜底手动放置合法解）
- 双击已找到的格子会错误标记 X（增加 `revealed` 检查）
- 触摸取消后鼠标状态卡死（增加 `touchcancel` 处理）
